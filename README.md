# dustte-website

Source for **www.dustte.com** — DUSTTE LLC, Sharjah, UAE.

- `index.html` — DUSTTE Marketing (homepage): marketing support, ad spend and campaign management for other businesses.
- `trading.html` — DUSTTE Trading: farm-direct Indian green cardamom, black pepper and coconut products.
- `thank-you.html` — form confirmation page.
- `404.html` — not-found page.
- `products.html` — legacy URL, redirects to `trading.html`.

Static site hosted on GitHub Pages. Contact forms submit via FormSubmit to irshad@dustte.com.
